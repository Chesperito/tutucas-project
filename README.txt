#Tutuca's Restaurant Website

Online ordering system for a pizzeria, allowing customers to customize their orders and send them directly via WhatsApp.

## Features

- Shopping cart
- Flavor selection (with limits)
- Custom meal kit creation
- Automatic sending to WhatsApp
- Business hours control
- Integration with Google Sheets (order tracking and printing)
- Dynamic menu

## Technologies

- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets

## Responsiveness

Project optimized for mobile devices, ensuring ease of use during ordering.

## How it works

1. Customer selects items
2. Compiles the order
3. Finalizes via WhatsApp
4. Order is automatically recorded

##  Objective

To streamline the pizzeria’s ordering process, making it faster, more organized, and more accessible.
